Slash Commands

Type in chat and press Enter.

  • /clear - Clear chat screen
  • /help - Show this guide
  • /run <command> - Run shell command (e.g. /run git status)
  • /read <file> - Read file content (e.g. /read package.json)
  • /write <file> <content> - Create or edit a file
  • /git <args> - Run git commands
  • /npm <args> - Run npm commands
  • /ls, /cat, /mkdir, /pwd - Common shell shortcuts
  • /list or /files - Refresh project file list

Note: Commands starting with / are executed locally and not sent to AI.
