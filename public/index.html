📚 คำสั่ง Slash (/)

พิมพ์ในช่องแชทแล้วกด Enter

  • /clear - ล้างหน้าจอแชท
  • /help - แสดงคู่มือนี้
  • /run <คำสั่ง> - รันคำสั่ง Shell จริง (เช่น /run git status)
  • /ls - แสดงไฟล์ในโฟลเดอร์ปัจจุบัน
  • /cat <ไฟล์> - อ่านเนื้อหาไฟล์ (เหมือน /read)
  • /read <ไฟล์> - อ่านเนื้อหาไฟล์ (เช่น /read package.json)
  • /write <ไฟล์> <เนื้อหา> - สร้าง/แก้ไขไฟล์
  • /git <args> - รันคำสั่ง Git (เช่น /git status)
  • /npm <args> - รันคำสั่ง NPM (เช่น /npm install)
  • /mkdir /rm /cp /mv /pwd /echo /touch - คำสั่ง shell ทั่วไป
  • /list หรือ /files - รีเฟรชรายการไฟล์โปรเจกต์

หมายเหตุ: คำสั่งที่ขึ้นต้นด้วย / จะไม่ส่งไป AI แต่จะเรียกทำงานบนเครื่องจริงทันที
